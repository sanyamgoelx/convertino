Convertino

Milestone 7 · video, data, archives

Select files in File Explorer or on the desktop, then press Hold Alt and right-click a file (or press ). The wheel opens at your pointer; pick a format. Images, audio, video, PDFs, documents, data files and archives convert for real; progress shows in the corner of the screen. This window logs each press and pick.

Waiting for the hotkey You can close this window; Convertino keeps running in the system tray.
    Logs are written to Convertino's log folder on every hotkey press.
